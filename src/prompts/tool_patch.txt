Apply exact replacements to one existing UTF-8 file. The input is JSON:

`{ "path": "src/example.rs", "edits": [{ "oldText": "old", "newText": "new" }] }`

Every `oldText` must occur exactly once in the original snapshot. Replacements
must not overlap, and all edits are validated before the file is written. Use
`write`, `delete`, and `rename` for file lifecycle operations.
